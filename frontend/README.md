# Frontend

Minimal Expo Router starter with automatic light and dark themes.

## Get started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start Expo:

   ```bash
   npx expo start
   ```

Start building the UI in `src/app/index.tsx`. Keep route files in `src/app/` and shared code elsewhere in `src/`.
